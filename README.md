## The Problem

Modern growth teams rely on slow, manual analysis and gut feelings. Trends move in microsecond intervals across social platforms, and by the time you've drafted a campaign, the cultural zeitgeist has already moved on. **You are leaving alpha on the table.**

There is no platform that treats marketing budgets the way a quantitative hedge fund treats capital — with real-time signal processing, multi-model evaluation, automated risk assessment, and portfolio-style campaign management.

## The Solution

**Avoir** is an autonomous AI Quantitative Engine. We operate as the **AI-Native Agency + AI Hedge Fund combo**. We ingest real-time social sentiment, generate precision-targeted algorithmic campaigns through a proprietary multi-tier AI failover cascade, evaluate them through AI red-teaming and synthetic focus groups, and deploy capital based on predictive ROI models — all in under 10 seconds.

> 🔥 *"Signal Detected: Viral anomaly in creator economy. Executing high-conviction Omni-Deck campaign. Projected ROI: 420%."* — Generated by Avoir

## 🧬 Core Thesis — Why Agency + Hedge Fund Is One System

This isn't a marketing metaphor. The architecture literally treats campaigns as financial instruments:

| Marketing Concept | Hedge Fund Equivalent | How Avoir Implements It |
|---|---|---|
| Ad spend allocation | Capital deployment | Capital Deployment Simulator (`CapitalDeploymentSimulator.tsx`) |
| Trending topics with low competition | Mispriced assets / arbitrage | Live Arbitrage Feed (`LiveArbitrageFeed.tsx`) |
| Campaign A/B testing | Portfolio diversification | Genome Mode — 3 divergent variants per prompt |
| AI red-team review | Risk modeling | The Crucible — skeptical consumer + fixer AI pass |
| Performance analytics | P&L reporting | Intelligence Flywheel (`intelligence.ts`) |
| Campaign momentum tracking | Position monitoring | Signal Decay Monitor (real-time SSE) |

**Both halves share the same LLM cascade, the same DynamoDB tables, the same SSE streaming pipeline, and the same Redis cache.** There is no "agency module" and "hedge fund module" — there is one integrated system where the agency side *generates* and the hedge fund side *evaluates and allocates*.

## 🔷 Diamond Cascade Architecture

Our proprietary 6-tier AI cascade provides **100% uptime guarantee** with intelligent failover. Each tier uses raw HTTP requests via Python's `urllib` — zero third-party SDK dependencies — to minimize Lambda cold-start time.

```text
User Request
     ↓
 ┌────────────────────────────────────────────────┐
 │  TIER 1  Gemini 3 Flash (Key 1)    ~2B params  │
 └──────────────────────┬─────────────────────────┘
                        ↓ failover
 ┌────────────────────────────────────────────────┐
 │  TIER 2  Gemini 3 Flash (Key 2)    Key rotation │
 └──────────────────────┬─────────────────────────┘
                        ↓ failover
 ┌────────────────────────────────────────────────┐
 │  TIER 3  GPT-OSS 120B (Groq)      300+ tok/sec │
 └──────────────────────┬─────────────────────────┘
                        ↓ failover
 ┌────────────────────────────────────────────────┐
 │  TIER 4  Arcee Trinity 400B       Quant King   │
 └──────────────────────┬─────────────────────────┘
                        ↓ failover
 ┌────────────────────────────────────────────────┐
 │  TIER 5  Llama 3.3 70B            The Shield    │
 └──────────────────────┬─────────────────────────┘
                        ↓ failover
 ┌────────────────────────────────────────────────┐
 │  TIER 6  Titanium Shield (Mock)   Local Fallback │
 └────────────────────────────────────────────────┘
     ↓
 Strategy Delivered (100% Uptime)
```

The system has **evolved into a dual-brain architecture**:
- **Backend Cascade** (`aws_lambda_handler.py`, 958 lines) — heavyweight, zero-dependency engine designed for AWS Lambda.
- **Frontend Orchestrator** (`bedrock.ts`) — newer, feature-rich brain running in Next.js API routes with Crucible, Genome Mode, and Synthetic Focus Group evaluation layers.

Both systems can operate independently. The cascade's core principle — *"never fail, always degrade gracefully"* — has been adopted throughout the entire architecture.

## ⚡ Quick Start

### Prerequisites
- Node.js 18+
- Python 3.11+
- AWS Account (Cognito, DynamoDB)
- Stripe Account

### 1. Clone & Install

```bash
git clone https://github.com/SxBxcoder/Avoir.git
cd Avoir

# Frontend
cd avoir-ai
npm install

# Backend
cd ../backend
pip install -r requirements.txt
```

### 2. Configure Environment
Create `avoir-ai/.env.local` and populate it with your AWS, Upstash, and Stripe keys. See `avoir-ai/.env.example` for details.

### 3. Provision Database
```bash
cd avoir-ai
node scripts/create-tables.mjs
```

### 4. Run Development Servers

```bash
# Terminal 1 — Backend (SSE streams, simulation API)
cd backend && python server.py

# Terminal 2 — Frontend (Next.js)
cd avoir-ai && npm run dev
```

Open **http://localhost:3000** to access the dashboard.
