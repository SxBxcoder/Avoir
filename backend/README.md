# Prachar.ai Backend

FastAPI server for the Creative Director Agent.

## Setup

### 1. Install Dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 2. Configure AWS Credentials

Create a `.env` file in the `backend` directory:

```env
AWS_REGION=us-east-1
AWS_ACCESS_KEY_ID=your_access_key
AWS_SECRET_ACCESS_KEY=your_secret_key
BEDROCK_KB_ID=your_knowledge_base_id
GUARDRAIL_ID=your_guardrail_id
GUARDRAIL_VERSION=DRAFT
S3_BUCKET=prachar-ai-assets
DYNAMODB_TABLE=prachar-campaigns
```

### 3. Run the Server

```bash
python server.py
```

The server will start at `http://localhost:8000`

### Daily Alpha Brief

**GET** `/api/alpha-brief`

Returns today's Daily Alpha Brief — the top trend anomaly with a tactical campaign hook, generated by Gemini and cached in Upstash Redis.

- First call of the day generates the brief via Gemini (`gemini-3-flash-preview`) and caches it until UTC midnight.
- Subsequent calls serve the cached copy (zero LLM latency).
- `?force=true` bypasses the cache and regenerates — it requires an `X-Admin-Token` header matching the `ALPHA_BRIEF_ADMIN_TOKEN` env var (see `.env.example`).
- Failure cascade: Gemini (2 keys) → Trend Sniper → Titanium Shield mock (never errors out).

Response:
```json
{
  "date": "2026-08-10",
  "trend": {
    "title": "AI Micro-Agents",
    "description": "Explosive growth in single-purpose AI agents replacing complex SaaS.",
    "momentum": "peaking"
  },
  "brief": {
    "plan": {
      "hook": "SaaS is dead. Say hello to Micro-Agents.",
      "offer": "Deploy 5 specialized AI agents for the cost of 1 generic tool.",
      "cta": "Start building your automated army today"
    },
    "captions": ["...", "...", "..."]
  },
  "generated_by": "gemini-3-flash-preview",
  "generated_at": "2026-08-10T00:15:00.000000Z"
}
```

Requirements (see `.env.example`): `GEMINI_API_KEY` / `GEMINI_API_KEY_2` and `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`. If Redis is unconfigured the generator still works — it just skips caching. The daily cron (`aws_lambda_daily_cron.py`) pre-warms the brief via EventBridge.

## Development

The server runs with auto-reload enabled. Any changes to `agent.py` or `server.py` will automatically restart the server.

## Troubleshooting

### Port Already in Use

If port 8000 is busy, change the port in `server.py`:

```python
uvicorn.run("server:app", host="0.0.0.0", port=8001, reload=True)
```

### CORS Issues

If you get CORS errors, ensure your Next.js app is running on `http://localhost:3000`. If using a different port, add it to the `allow_origins` list in `server.py`.

### AWS Credentials

Ensure your AWS credentials have permissions for:
- Bedrock Runtime (InvokeModel)
- Bedrock Agent Runtime (Retrieve)
- S3 (PutObject, GetObject)
- DynamoDB (PutItem, GetItem, Query)
